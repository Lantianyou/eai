# Physical Intelligence 的模型 API

今天 [Physical Intelligence 发布了 Pi API](https://www.pi.website/blog/api-beta)：对于机器人/部署公司，他们可以直接上传数据，获得 Fine-Tune 到适配他们场景的推理 API。这是具身行业向正确抽象和分工走的第一步。Physical Intelligence 作为专注模型层的公司，服务了全球 15 家机器人创业公司。

![Pi API：上传数据，在我们管理的算力和基础设施上启动微调，并通过托管网关访问微调后的模型来运行推理。](/images/pi-api.png)

目前尚不清楚计费的模式，我觉得更接近于 [Thinking Machines 的模式](https://tinker-docs.thinkingmachines.ai/tinker/models/models_and_pricing/)，会根据训练的数据量和推理的 Token 数计费。
