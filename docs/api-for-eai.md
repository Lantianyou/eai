# API for eai

今天 [PhysicalIntelligence 发布了 API](https://www.pi.website/blog/api-beta)，对于机器人/部署公司，他们可以直接上传数据，获得 Fine Tune 到适配他们场景的推理 API。这是具身行业向正确抽象和分工走的第一步，Physical Intelligence 作为专注模型层的公司，服务了全球 15 家机器人创业公司。目前尚不清楚计费的模式，我觉得更接近于 [Thinking Machine 的模式](https://tinker-docs.thinkingmachines.ai/tinker/models/models_and_pricing/)，会根据训练的数据量和推理的 Token 数计费。

![Pi API：上传数据，在我们管理的算力和基础设施上启动微调，并通过托管网关访问微调后的模型来运行推理。](/images/pi-api.png)

在首发的 Blog 里，介绍了 15 家客户，1 家是挖掘机，另外 14 家都是夹爪。推理全部在云端。大部分是仓储/制造业，户外的农业和建筑行业都有涉及。下面逐家过一遍它们的产品和业务。

### 1. Almond

**给具身智能开发团队提供机器人硬件和数据采集工具。** 主打产品是 **Axol 双臂机器人**，配套提供移动底座、摄像头、计算模块和遥操作功能；另有 **Mantis UMI 手持式数据采集夹爪**，让人不依赖机器人本体也能采集操作示范。可以理解为：给训练、开发机器人 AI 的团队提供"身体"和采集装备，而不是只做某个行业的专用机器。([Almond](https://almond.bot/))

### 2. Argon Robotics

**重点解决机器人自主操作"太慢"的问题。** 它训练和部署高速操作模型，研究如何通过优化示范数据、动作执行和人工纠错数据，让机器人更快地完成任务。公开研究涉及拿取餐盘、双臂交接、物品抓放等；目标场景包括厨房、仓库等对作业速度敏感的地方。其公开结果仍来自有限任务，不能把官网"全球最快"的宣传直接当作普遍成立的结论。([Argon Robotics](https://www.argonrobotics.ai/research/scaling-and-speeding-up-robots-in-the-real-world))

### 3. Chef Robotics

**做食品生产线上的配餐、分装机器人。** 机器人结合 **ChefOS**，把蔬菜、肉类、米饭、酱汁等按份量放到餐盘、餐盒或其他食品载体上，适应食材形状和菜单变化。客户场景包括预制餐、中央厨房、航空配餐等，并提供机器人租赁及维护服务。重点是**食品组装与分装**，不是家用自动炒菜锅。([Chef Robotics](https://www.chefrobotics.ai/))

### 4. Deft／Deft Robotics

**把轮式人形机器人部署进工厂，接手仍依赖人工的操作工位。** 将机器人硬件、基础模型、现场数据采集和生产流程整合起来，重点面向汽车制造等场景。已公布的案例包括压缩机壳体、汽车横梁等零部件的产线上料；也针对配套备料、装配及线缆处理等难以用传统自动化覆盖的任务。其定位更接近**工厂机器人解决方案与系统集成商**，而非单纯卖机器人本体。([Deft Robotics](https://www.deftai.co/))

### 5. Dream Machines

**帮助欧洲中小制造企业，通过"工人示范"教会机器人干活。** 来自瑞士苏黎世的团队，把机器人 AI 做成可接入现有工作台的完整方案，针对电路板测试、电池插装、不同零件的机床上下料、不规则物品分拣和质检等任务。重点是减少逐动作编程，让懂工艺的工人也能配置自动化；官网说明目前在推进首批欧洲制造商试点。([Dream Machines](https://dream-machines.eu/why))

### 6. Formic Robotics／Formic

**以租赁服务模式提供工厂自动化。** 主要面向中型食品、饮料和消费品制造商，提供装箱、码垛、设备上下料、托盘缠膜等系统。客户按固定月费获得机器人、安装、技术支持和维护，减少前期购买设备及自建自动化团队的负担。核心是**"机器人即服务"与持续运营**，不是只研发一种人形机器人。([Formic](https://formic.co/))

### 7. Foundry／Foundry Robotics

**用 AI 和机器人建设柔性装配代工厂。** 它提出的 **"Everything Factory"**，是用模块化机器人工作单元承接不同产品的装配，覆盖电池包、复杂机械组件，以及国防和军民两用硬件。一个重要区别是：其商业切入点是**替客户制造、装配产品**，而不只是把机器人卖给客户。([Foundry Robotics](https://foundryrobotics.ai/))

### 8. Frontier Machines

**做可以接替工厂重复性人工工位的工业机器人。** 主打产品 **FR-2**，强调在现有人员工位部署，并通过示范学习不同任务。官网列出的用途包括操作自动装袋机、注塑浇口修剪、折弯机操作、定量灌装、配套备料和装配。它瞄准的不只是生产线末端码垛，而是**生产过程里尚未自动化的中间工位**。([Frontier Machines](https://www.frontiermachines.ai/))

### 9. General Instinct

**给机器人 AI 团队提供后训练和部署基础设施。** 产品 **Instinct Edge** 通过模型蒸馏、量化和运行优化，把大型模型部署到机器人、无人机等设备的有限算力硬件上，争取实现低延迟、离线运行。可以理解为：解决**"模型在云端能跑，怎样放到真实设备上稳定运行"**的问题，而不是主要靠卖机器人整机赚钱。([Y Combinator](https://www.ycombinator.com/companies/general-instinct))

### 10. Hackathon

**不是公司，而是黑客松中的机器人演示项目。** 它被放在同一组案例中，用来展示开发者使用 Pi API 做应用的情况，不应作为一家独立机器人企业来比较。([Unite.AI](https://www.unite.ai/physical-intelligence-opens-pi-api-beta-for-robot-foundation-models/))

### 11. Intuition.dev

**做工业和服务场景中的 AI 机器人部署与运维。** 官网强调从安装配置、数据采集，到维护、异常恢复的全流程服务，目标是不仅让机器人"演示一次"，而是让它在客户现场持续工作。其定位偏向**连接机器人、AI 模型和实际业务的部署服务商**，不宜仅根据截图中的布料操作演示，把它归为一家专门做叠衣机器人的公司。([Intuition Robotics](https://intuition.dev/))

### 12. Omakase／Omakase Robotics

**日本 ZEALS 旗下的机器人业务，主打医院、照护及其他室内服务场景。** 产品是 **D1 紧凑型人形机器人**，结合双臂、移动底座，以及导航、交互和操作学习软件，目标任务包括接待、指路、物品运送和作业辅助，也面向酒店、制造与物流场景。你截图里倒茶的就是 D1；它的定位是**服务和照护辅助**，不是手术机器人。([Zeals](https://zeals.ai/news/d1-launch-2026))

### 13. robot.com

**经营多种面向实际岗位的机器人产品和部署服务。** 产品包括校园、人行道上的配送机器人，物流搬运机器人，以及 **R-noid 人形机器人**。R-noid 面向厨房辅助、装箱、订单拣选、折叠毛巾床单和接待等工作。可以理解为：不是押注单一形态，而是用不同机器人覆盖**配送、物流和服务业中的具体岗位**。([robot.com](https://www.robot.com/robotics))

### 14. Ultra

**做仓库里的包装、分拣和配套备料机器人。** 主打 **Operator／OP1**，是面向固定工位的双臂操作机器人，重点任务包括电商订单包装、装袋、封口、分拣和组合备料。它强调把机器人推到已有工位、接入电源后部署，不以双足行走为卖点；官网已列出美国多个仓库的部署案例。([Ultra Robotics](https://ultra.tech/))

### 15. Yondu

**做第三方物流仓库的拣货与订单履约自动化。** 利用现成机器人硬件，结合自己的遥操作、机器人学习和系统集成能力，让机器人在已有货架和仓库布局中识别、拿取和放置商品。路线是先通过遥操作和人工支持投入使用，再逐步提高自主化程度。与 Ultra 相比，它的切入点更偏**货架／料箱拣选和移动履约**，而 Ultra 更偏包装工位。([yondu.ai](https://yondu.ai/))
